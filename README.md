# VPN Traffic Analysis Lab

A cybersecurity project that captures live network packets and analyses traffic to identify VPN-like and normal-like patterns.

### Features
- Live packet capturing
- TCP and UDP traffic analysis
- Payload entropy analysis
- VPN-related port detection
- Tor exit-node matching
- Interactive dashboard with charts
- CSV export of results

### Tech Stack
Python, Flask, Scapy, HTML, CSS and JavaScript.

**Note:** This project uses heuristic-based analysis. It indicates VPN-like traffic but does not guarantee VPN detection.
